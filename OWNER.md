# Изменения и управление приложением

Этот проект подготовлен по вашему заданию. Исходный код приложения передаётся вам: вы можете использовать, изменять и дополнять его, поручать доработки другому разработчику и размещать приложение на своём хостинге. Для изменения кода согласие помощника не требуется. Приложение не вводит ограничений на редактирование исходников.

Администрирование GitHub-репозитория и хостинга остаётся у владельца соответствующих аккаунтов. Настройки доступа к репозиторию эта сборка не меняет. Сохраните архив исходников как независимую копию, которую можно перенести к другому провайдеру.

Рецепты и продукты редактируются в `src/recipes.js`, `src/catalog.js`, `src/foods.js`. Подбор меню — `src/planner.js`; интерфейс — `src/planner-ui.js`, `src/main.js`, `src/style.css`. Справочник для фото — `src/photo-foods.js`. Расчёт КБЖУ — `src/nutrition.js`.

После доработки запустите `npm test`, `npm run build`, `npm run export`. Последняя команда обновит скачиваемые файлы и архивы. В GitHub Pages изменения публикуются через workflow `.github/workflows/pages.yml` после отправки в ветку `main`, если Pages включён.

Сторонние зависимости сохраняют свои лицензии. Например, Vite распространяется по MIT; лицензии его зависимостей входят в устанавливаемые npm-пакеты. Передача исходников приложения не отменяет условия этих лицензий.

Секреты и настройки конкретной среды не входят в архив. ИИ-ключ хранится на сервере, не в HTML или клиентском коде.
