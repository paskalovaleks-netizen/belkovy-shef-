# Белковый шеф на iPhone

Для установки с иконкой нужен размещённый сайт с HTTPS. Скачанный HTML в обычном просмотрщике приложения «Файлы» не запускает JavaScript-приложение и не заменяет установку через Safari.

## Установка

1. Дождитесь успешной публикации сайта. Рабочий адрес показывает GitHub в **Settings → Pages** или последний успешный запуск workflow **Actions → Publish chef app**.
2. Откройте этот адрес в Safari на iPhone.
3. Нажмите **Поделиться → На экран «Домой» → Добавить**. Если доступен переключатель **Открывать как веб-приложение**, включите его.
4. В разделе «Белковый шеф на телефоне» дождитесь сообщения, что меню и рецепты готовы к работе без интернета.
5. Открывайте приложение с появившейся иконки.

Выбор продуктов, меню на 30 дней, случайная замена с тем же белком, каталог и ручной расчёт работают без сети после первой загрузки сайта. Настройки и меню сохраняются в хранилище этого устройства. Они не переносятся автоматически из браузера на компьютере или другого адреса. Для резервной копии рациона есть экспорт TXT. Очистка данных сайта удаляет локальные настройки.

## Публикация на GitHub Pages

В проекте подготовлен workflow `.github/workflows/pages.yml` для ветки `main`.

1. Владелец репозитория открывает **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. В **Actions → Publish chef app** запустите **Run workflow** либо отправьте новое изменение в `main`.
3. Дождитесь успешных jobs `build` и `deploy`. Используйте адрес из результата публикации, а не заранее предполагаемую ссылку.

Сервис Pages должен быть доступен для вашего аккаунта и типа репозитория. Не меняйте видимость приватного репозитория только ради публикации без собственного решения.

На GitHub Pages работают меню и ручной фотокалькулятор. Pages не запускает Node.js-сервер: **автораспознавание фото недоступно на этой статической площадке**. Для него нужен отдельный Node.js-хостинг и рабочий серверный ключ; ключ нельзя добавлять в frontend или GitHub Pages. В текущей облачной среде существующий ключ ранее получил ответ OpenAI `invalid_api_key` и требует исправления в защищённых настройках.

## Скачиваемые копии

- `belkovy-shef-mobile.html` — приложение в одном файле для совместимого браузера, без установки с иконкой на iPhone.
- `belkovy-shef-source.zip` — редактируемые исходники, инструкции, тесты и workflow; без ключей, зависимостей и Git-метаданных.
- `belkovy-shef-site.zip` — готовые файлы сайта; можно распаковать в корень HTTPS-хостинга или в каталог сайта. Серверный API в эту сборку не входит.

На Android можно попробовать открыть HTML через браузер из «Загрузок». Поддержка зависит от браузера и приложения, открывающего файл; надёжный вариант установки на обоих типах телефона — HTTPS-сайт.

Для обновления установленного приложения откройте сайт с интернетом после успешной публикации новой сборки. Перезагрузите приложение: service worker загрузит новую версию, не удаляя сохранённый профиль и меню. После изменения рецептов несовместимые старые рационы могут потребовать нового подбора.
